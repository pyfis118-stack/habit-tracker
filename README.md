# Habit Tracker — Streak

Полноценное React-приложение для отслеживания привычек: серии (streak),
XP и уровни, статистика, достижения, тёмная/светлая тема. Все данные
сохраняются локально в браузере (через `localStorage`) и не пропадают
после перезагрузки или закрытия приложения.

## Установка на Windows — пошагово

### 1. Установи Node.js

Приложению нужен Node.js версии 18 или новее.

1. Зайди на https://nodejs.org
2. Скачай версию **LTS** (рекомендуемую) для Windows
3. Запусти установщик и пройди установку с настройками по умолчанию
4. Перезагрузи компьютер (или хотя бы перезапусти терминал)

Проверь, что всё установилось. Открой **PowerShell** или **Командную строку**
(cmd) и введи:

```
node -v
npm -v
```

Должны появиться номера версий (например, `v20.11.0` и `10.2.4`). Если
команда не найдена — переустанови Node.js и перезапусти терминал.

### 2. Распакуй проект

Распакуй скачанный ZIP-архив в удобную папку, например `C:\Projects\habit-tracker`.

### 3. Открой терминал в папке проекта

В проводнике Windows зайди в папку `habit-tracker`, зажми **Shift**, нажми
правой кнопкой мыши в пустом месте папки и выбери **«Открыть окно PowerShell
здесь»** (или **«Открыть в терминале»** в Windows 11).

### 4. Установи зависимости

Введи в терминале:

```
npm install
```

Это скачает все нужные библиотеки (React, Vite, Tailwind, иконки и т.д.)
в папку `node_modules`. Первый раз может занять пару минут.

### 5. Запусти приложение

```
npm run dev
```

В терминале появится примерно такое сообщение:

```
  VITE ready
  ➜  Local:   http://localhost:5173/
```

Зажми **Ctrl** и кликни по ссылке (или просто открой её в браузере) —
приложение откроется на `http://localhost:5173`.

### 6. Как проверить, что всё работает

- Создай привычку через кнопку «+ Создать привычку»
- Отметь её выполненной галочкой — появится сообщение и обновится XP
- Отметь все привычки за день — появится баннер «День закрыт» и конфетти
- Обнови страницу в браузере (F5) — привычки и прогресс должны остаться
- Загляни в «Настройки» — попробуй сменить тему, имя, акцентный цвет

Чтобы остановить сервер разработки, вернись в терминал и нажми `Ctrl + C`.

## Дальнейшая работа с проектом

- Чтобы снова запустить приложение в другой раз — просто открой терминал в
  папке проекта и введи `npm run dev` (заново `npm install` делать не нужно,
  если ты не менял `package.json`).
- Чтобы собрать готовую production-версию (статические файлы, которые можно
  разместить на любом хостинге): `npm run build`. Результат появится в
  папке `dist`.
- Чтобы посмотреть собранную версию локально: `npm run preview`.

```
└── src/
    ├── main.jsx           # точка входа React, монтирует приложение
    ├── App.jsx            # обёртка, рендерит HabitTracker
    ├── HabitTracker.jsx   # весь функционал трекера привычек (без изменений)
    ├── storage-shim.js    # хранилище данных поверх localStorage
    └── index.css          # подключение Tailwind
```

## Про хранение данных

Компонент `HabitTracker.jsx` изначально написан для среды Claude Artifacts,
где есть встроенное постоянное хранилище `window.storage`. Вне этой среды
такого объекта не существует, поэтому в файле `src/storage-shim.js` реализован
точно такой же API (`get`/`set`/`delete`/`list`), но поверх обычного
`localStorage` браузера. Сам функционал HabitTracker при этом не менялся —
он просто пользуется тем же API, что и раньше.

Если позже захочешь подключить настоящий сервер и базу данных вместо
`localStorage` — нужно будет заменить реализацию внутри `storage-shim.js`
(например, на запросы к своему API), не трогая остальной код.

## Возможные проблемы

- **`npm install` завершается с ошибкой** — проверь, что Node.js установлен
  (`node -v`), и что есть доступ в интернет (зависимости скачиваются из npm).
- **Порт 5173 занят** — Vite сам предложит свободный порт, просто следуй
  ссылке из терминала.
- **Приложение открылось, но выглядит "сломанным" (без стилей)** — убедись,
  что `npm install` завершился без ошибок, и перезапусти `npm run dev`.
